## 🎮 1. そもそも「RPG（ロールプレイングゲーム）」とは？

私たちが普段楽しんでいるRPGは、一体どのような要素で成り立っているでしょうか？
ゲームの構成を大きく分けると、以下のようになります。

* **目的（ゴール）：** ラスボス（魔王）を倒して世界を平和にすること
* **過程（冒険と成長）：** 
  * 魔王のいる場所まで旅をする（**移動・マップ**）
  * 敵と戦って強くなる（**バトル・鍛錬**）
  * HPを回復したり、行動を選択したりする（**状態管理・コマンド**）

一見複雑に見えるゲームの世界も、プログラミング（作る側）の視点でバラバラに分解してみると、実はとてもシンプルな **5つのプログラミング要素** の組み合わせでできています！

### 💡 遊ぶ側の「体験」を 作る側の「プログラム」へ分解してみよう

| 遊ぶ側の体験（ゲーム現象） | 作る側の視点（プログラミング要素） | Pythonで使う仕組み |
| :--- | :--- | :--- |
| **① 目的（勝利と敗北）** | 条件を満たしたらシーン（画面）を切り替える **「判定」** | `if hp <= 0:` / シーン遷移 |
| **② バトルと成長** | ダメージや経験値、回復による **「数値の計算」** | 足し算・引き算（`player["hp"] -= damage`） |
| **③ 移動と冒険** | キャラクターの画面上の位置を覚える **「座標」** | X座標・Y座標の更新（`x, y`）と壁判定 |
| **④ コマンド選択** | プレイヤーが選んだ行動に応じて処理を変える **「条件分岐」** | `if / elif / else` |
| **⑤ ステータス管理** | 勇者や敵のHP・攻撃力などの情報をまとめる **「データ構造」** | 辞書型（`dict`）/ `json` ファイル |

## 🗺️ 2. 2日間の開発ロードマップ（計8時間）

本ワークショップでは、いきなり複雑なグラフィックを作るのではなく、**「仕組み（ロジック）」** から **「見た目（グラフィック）」** へとステップアップしていきます。

```
【1日目：CUIテキストRPG編】(4時間)
  ・Pythonの基本（変数、if、while、関数）をマスター
  ・辞書型（dict）で勇者のステータスを管理
  ・json ファイルからモンスターデータを読み込む
  ・ターミナル（文字画面）で動くコマンド選択式RPGを構築！
       │
       ▼ (1日目に作ったロジックをそのまま移載！)
【2日目：Pyxel 2DレトロRPG編】(4時間)
  ・レトロゲームエンジン「Pyxel」の導入
  ・16x16ドット絵の描画と2Dマップの歩行（壁判定）
  ・日本語ドット絵フォント（8x8）によるメッセージ表示
  ・タイトル〜マップ〜バトル〜ゲームオーバーの一巡するゲームループ完成！
```

1日目に作成するプレイヤーのデータ構造やダメージ計算式は、**2日目のPyxel版でそのまま再利用**します。「自分が書いたプログラムの仕組みが、そのままグラフィックの世界で動く！」というプログラミングの醍醐味をぜひ体感してください。

## 🧠 3. プログラミング学習を楽しむための3つのマインドセット

最後に、この2日間を最高に楽しむための心構えをお伝えします。

1. **エラー（赤文字）は「失敗」ではなく「ヒント」！**
   プログラムが動かなくなったり赤い文字が表示されても焦る必要はありません。コンピュータが「ここを直せば動くよ！」と教えてくれているメッセージです。講師やTA（ティーチングアシスタント）と一緒に1つずつ解決していきましょう。

2. **小さな「動いた！」を思いきり喜ぼう！**
   「画面に文字が出た」「矢印キーで1マス動いた」「ダメージが計算された」——それらはすべて、あなたが作ったゲームが命を吹き込まれた瞬間です。完成に向かって進む1ステップずつを楽しんでください。

3. **自分だけの工夫（アレンジ）をしてみよう！**
   基本のコードが完成したら、主人公の名前を変えてみたり、モンスターの攻撃力を書き換えてみたりして、自由にゲームを改造してみましょう！

それでは、いよいよ冒険の始まりです！まずは1日目の「Python基礎 & CUIテキストRPG開発」からスタートしましょう！
